# Skill template

Copy this file to `storage/skills/<skill-name>/SKILL.md`.

```markdown
---
name: skill-name
version: 0.1.0
---
# Purpose

What the skill does.

# Inputs

What the caller provides.

# Outputs

What the skill returns or changes.

# Execution flow

Ordered steps, with a Mermaid diagram when the flow has branches.

# Error handling

How failures are detected, logged, and returned.

# Logging

Logger name, level, and fields included on each line.

# Versioning

When to bump the skill version.

# Test coverage

Test modules that lock this skill.

# Documentation references

Related Markdown files.
```
